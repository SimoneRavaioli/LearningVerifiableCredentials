Separate-service proof of concept

This mode keeps the learner’s key in this browser. Issuer, authority and verifier run as separate Node processes and hold only their own keys. This is a synthetic local integration using a documented JSON exchange, not OpenID certification or an external-wallet result.

Run locally

npm ci
npm run build
# Set OPERATOR_PASSWORD to your own 16+ character password
npm start

Open this page on the computer running the services. HTTPS and separate hosts must be configured for a phone/remote pilot; localhost on your phone is not this computer.
